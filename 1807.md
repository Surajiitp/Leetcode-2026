# 1807. Evaluate the Bracket Pairs of a String

## Problem Statement

You are given a string `s` that contains lowercase English letters, spaces, and brackets.

The string contains some **bracket pairs** `(key)`. You are also given a 2D array `knowledge`, where each pair contains a key and its corresponding value.

For every `(key)` in the string:

* If the `key` exists in `knowledge`, replace `(key)` with its corresponding value.
* If the `key` does not exist, replace it with `?`.

Return the resulting string.

---

## Example

### Input

```text
s = "(name)is(age)yearsold"

knowledge = [
    ["name", "bob"],
    ["age", "two"]
]
```

### Output

```text
"bobistwoyearsold"
```

### Explanation

```text
(name) → bob
(age)  → two
```

Therefore:

```text
(name)is(age)yearsold
        ↓
bobistwoyearsold
```

---

## Approach

We use an `unordered_map` to store the key-value pairs from `knowledge`.

### Steps

1. Store every `key → value` pair in an `unordered_map`.
2. Traverse the string `s`.
3. If the current character is not `'('`, add it directly to the answer.
4. If we encounter `'('`:

   * Find the corresponding `')'`.
   * Extract the key between the brackets.
   * Check whether the key exists in the map.
   * If it exists, append its value.
   * Otherwise, append `?`.
5. Continue until the entire string is processed.
