# 628. Maximum Product of Three Numbers

## Problem Statement

Given an integer array `nums`, find the maximum product that can be obtained from any three numbers.

Return the maximum product.

**LeetCode Link:** https://leetcode.com/problems/maximum-product-of-three-numbers/

---

## Example 1

**Input**

```text
nums = [1,2,3]
```

**Output**

```text
6
```

---

## Example 2

**Input**

```text
nums = [1,2,3,4]
```

**Output**

```text
24
```

---

## Example 3

**Input**

```text
nums = [-1,-2,-3]
```

**Output**

```text
-6
```

---

## Intuition

The maximum product can be formed in two ways:

1. Three largest positive numbers.
2. Two smallest (most negative) numbers and the largest positive number.

Why?

Two negative numbers multiply to become positive.

Example:

```text
[-10,-10,5,2]
```

Product:

```text
(-10) × (-10) × 5 = 500
```

which is larger than:

```text
5 × 2 × (-10) = -100
```

---

## Algorithm

1. Sort the array.
2. Compute:
   - Product of the last three elements.
   - Product of the first two and the last element.
3. Return the larger product.

---

## C++ Solution

```cpp
class Solution {
public:
    int maximumProduct(vector<int>& nums) {
        sort(nums.begin(), nums.end());

        int n = nums.size();

        return max(
            nums[n - 1] * nums[n - 2] * nums[n - 3],
            nums[0] * nums[1] * nums[n - 1]
        );
    }
};
```

## Complexity Analysis

- **Time Complexity:** `O(n log n)`
- **Space Complexity:** `O(1)`

---

## Optimal Approach (Without Sorting)

Maintain:

- Three largest numbers
- Two smallest numbers

in one traversal.

Time Complexity becomes:

```text
O(n)
```

Space Complexity:

```text
O(1)
```
