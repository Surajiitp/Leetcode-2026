# 1358. Number of Substrings Containing All Three Characters

## 📝 Problem Statement

Given a string `s` consisting only of characters `'a'`, `'b'`, and `'c'`, return the number of substrings that contain **at least one occurrence** of all three characters.

**LeetCode Link:** https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/

---

## 💡 Approach 1: Sliding Window

We use the **Sliding Window** technique to efficiently count all valid substrings.

### Algorithm

1. Initialize two pointers `left` and `right`.
2. Maintain the frequency of `'a'`, `'b'`, and `'c'` in the current window.
3. Expand the window by moving `right`.
4. Once the window contains all three characters:
   - Every substring starting from `left` and ending at any index from `right` to `n-1` is valid.
   - Add `n - right` to the answer.
   - Shrink the window by moving `left`.
5. Continue until the end of the string.

---

## ✅ C++ Solution

```cpp
class Solution {
public:
    int numberOfSubstrings(string s) {
        vector<int> cnt(3, 0);
        int left = 0;
        int ans = 0;
        int n = s.size();

        for (int right = 0; right < n; right++) {
            cnt[s[right] - 'a']++;

            while (cnt[0] > 0 && cnt[1] > 0 && cnt[2] > 0) {
                ans += (n - right);
                cnt[s[left] - 'a']--;
                left++;
            }
        }

        return ans;
    }
};
```

## 🔍 Dry Run

### Input

```text
s = "abcabc"
```

### Process

| Right | Window | Valid? | Count Added | Total |
|------:|--------|---------|------------:|------:|
| 0 | a | ❌ | 0 | 0 |
| 1 | ab | ❌ | 0 | 0 |
| 2 | abc | ✅ | 4 | 4 |
| 3 | bca | ✅ | 3 | 7 |
| 4 | cab | ✅ | 2 | 9 |
| 5 | abc | ✅ | 1 | 10 |

**Output**

```text
10
```

## 💡 Why `ans += n - right`?

When the current window already contains all three characters:

```
[left ... right]
```

then all these substrings are also valid:

```
[left ... right]
[left ... right+1]
[left ... right+2]
...
[left ... n-1]
```

Hence, the number of valid substrings is:

```text
n - right
```

## 💡 Alternative Approach: Last Seen Indices

Track the most recent occurrence of `'a'`, `'b'`, and `'c'`.

For each position:

- Update the last occurrence.
- Find the minimum among the three indices.
- If all three characters have appeared, then `minIndex + 1` substrings ending at the current position are valid.

### C++ Solution

```cpp
class Solution {
public:
    int numberOfSubstrings(string s) {
        vector<int> last(3, -1);
        int ans = 0;

        for (int i = 0; i < s.size(); i++) {
            last[s[i] - 'a'] = i;
            ans += min({last[0], last[1], last[2]}) + 1;
        }

        return ans;
    }
};
```

## ⏱️ Complexity Analysis

### Sliding Window

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

### Last Seen Indices

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

---

## ✅ Key Takeaways

- Sliding Window is the most intuitive solution.
- Once a valid window is found, all larger windows ending later are automatically valid.
- The Last Seen Indices approach is shorter and equally efficient.
- Both solutions run in **linear time** with **constant extra space**.
