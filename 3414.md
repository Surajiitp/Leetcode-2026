# Maximum Weight of Non-Overlapping Intervals

## Problem Statement

You are given a 2D integer array `intervals`, where:

```text
intervals[i] = [li, ri, weighti]
```

Each interval starts at position `li`, ends at position `ri`, and has a corresponding weight.

You can choose **at most 4 non-overlapping intervals**.

The score is the sum of the weights of the selected intervals.

Return the **lexicographically smallest array of indices** among all selections having the maximum possible score.

### Important

Two intervals are considered **overlapping if they share any point**.

Therefore:

```text
[1, 3] and [3, 5]
```

are overlapping.

The next interval must satisfy:

```text
next_left > current_right
```

---

## Examples

### Example 1

**Input:**

```text
intervals = [[1,3,2],[4,5,2],[1,5,5],[6,9,3],[6,7,1],[8,9,1]]
```

**Output:**

```text
[2,3]
```

**Explanation:**

Choose intervals with indices `2` and `3`.

Their total weight is:

```text
5 + 3 = 8
```

which is the maximum possible score.

---

### Example 2

**Input:**

```text
intervals = [[5,8,1],[6,7,7],[4,7,3],[9,10,6],[7,8,2],[11,14,3],[3,5,5]]
```

**Output:**

```text
[1,3,5,6]
```

Their total weight is:

```text
7 + 6 + 2 + 3 = 18
```

---

## Approach

We use:

* Sorting
* Binary Search
* Dynamic Programming

### 1. Sort the intervals

Sort intervals by their starting position.

For every interval, keep its original index because the final answer must contain the original indices.

```text
[left, right, weight, originalIndex]
```

---

### 2. Find the next compatible interval

For every interval `i`, find the first interval whose starting position is strictly greater than the current interval's ending position.

We use binary search:

```cpp
a[mid][0] > a[i][1]
```

This is important because intervals sharing a boundary are considered overlapping.

For example:

```text
[1,3] and [3,5]
```

cannot both be selected.

---

### 3. Dynamic Programming

Let:

```text
dp[i][k]
```

represent the maximum score that can be obtained from interval `i` onward using at most `k` intervals.

For every interval, we have two choices:

#### Option 1: Skip the interval

```text
dp[i][k] = dp[i + 1][k]
```

#### Option 2: Take the interval

If we take interval `i`, we move to `next[i]`:

```text
weight[i] + dp[next[i]][k - 1]
```

So:

```text
dp[i][k] =
max(
    dp[i+1][k],
    weight[i] + dp[next[i]][k-1]
)
```

---

## Lexicographical Ordering

If two choices produce the same maximum score, we choose the lexicographically smaller index array.

For example:

```text
[1, 4]
```

is lexicographically smaller than:

```text
[2, 3]
```

because `1 < 2`.

Before comparing two selected index arrays, we sort their original indices.

---

## Complexity

Let `n` be the number of intervals.

### Time Complexity

Sorting:

```text
O(n log n)
```

Binary search for every interval:

```text
O(n log n)
```

DP has only `4` states for the number of selected intervals:

```text
O(4n)
```

Since every stored answer contains at most 4 indices, comparisons are constant-sized.

Overall:

```text
O(n log n)
```

### Space Complexity

```text
O(n)
```

for the sorted intervals, next indices, and DP states.

## C++ Solution

```cpp
class Solution {
public:
    vector<int> maximumWeight(vector<vector<int>>& intervals) {
        int n = intervals.size();

        // Store:
        // left, right, weight, original index
        vector<array<long long, 4>> a(n);

        for (int i = 0; i < n; i++) {
            a[i] = {
                intervals[i][0],
                intervals[i][1],
                intervals[i][2],
                i
            };
        }

        // Sort by starting position
        sort(a.begin(), a.end());

        // next[i] = first interval whose left > a[i].right
        vector<int> next(n);

        for (int i = 0; i < n; i++) {
            int lo = i + 1;
            int hi = n;

            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;

                if (a[mid][0] > a[i][1])
                    hi = mid;
                else
                    lo = mid + 1;
            }

            next[i] = lo;
        }

        // dp[i][k] = maximum score from i onward
        // using at most k intervals
        vector<vector<long long>> dp(
            n + 1,
            vector<long long>(5, 0)
        );

        // Store selected original indices
        vector<vector<vector<int>>> choice(
            n + 1,
            vector<vector<int>>(5)
        );

        for (int i = n - 1; i >= 0; i--) {
            for (int k = 1; k <= 4; k++) {

                // Option 1: Skip current interval
                dp[i][k] = dp[i + 1][k];
                choice[i][k] = choice[i + 1][k];

                // Option 2: Take current interval
                long long candidateScore =
                    a[i][2] + dp[next[i]][k - 1];

                vector<int> candidate =
                    choice[next[i]][k - 1];

                candidate.push_back((int)a[i][3]);

                // Final answer must be sorted by original index
                sort(candidate.begin(), candidate.end());

                if (candidateScore > dp[i][k] ||
                    (candidateScore == dp[i][k] &&
                     candidate < choice[i][k])) {

                    dp[i][k] = candidateScore;
                    choice[i][k] = candidate;
                }
            }
        }

        return choice[0][4];
    }
};
```

---

## Key Insight

The main idea is to convert the problem into a **weighted interval scheduling** problem with a limit of **4 selected intervals**.

For every interval:

```text
Take → jump to the next non-overlapping interval
Skip → move to the next interval
```

Binary search efficiently finds the next valid interval, while DP keeps track of the maximum score for up to 4 selections.

The lexicographical comparison is used only when two selections have the same score.
