# LeetCode 1716 – Calculate Money in Leetcode Bank

## 📌 Problem

Hercy saves money in the Leetcode bank every day.

* On the first Monday, he deposits `$1`.
* Each following day of the week, he deposits `$1` more than the previous day.
* Every new Monday, he deposits `$1` more than the previous Monday.

Given an integer `n`, return the total amount of money Hercy will have after `n` days.

---

## 💡 Approach

We can divide the `n` days into complete weeks and remaining days.

Let:

```text
weeks = n / 7
days  = n % 7
```

### Weekly Contribution

For the first week:

```text
1 + 2 + 3 + 4 + 5 + 6 + 7 = 28
```

For the second week:

```text
2 + 3 + 4 + 5 + 6 + 7 + 8 = 35
```

For the third week:

```text
3 + 4 + 5 + 6 + 7 + 8 + 9 = 42
```

Each week contributes **7 more** than the previous week.

So the total for `weeks` complete weeks is:

```text
28 + 35 + 42 + ... 
```

This is an arithmetic progression.

The sum can be calculated as:

```text
weeks * (28 + (28 + (weeks - 1) * 7)) / 2
```

For the remaining `days`, the next week's starting deposit is:

```text
weeks + 1
```

So the remaining contribution is:

```text
(weeks + 1)
+ (weeks + 2)
+ ...
+ (weeks + days)
```

---

## 🧠 Algorithm

1. Calculate the number of complete weeks:

   ```text
   weeks = n / 7
   ```

2. Calculate the remaining days:

   ```text
   days = n % 7
   ```

3. Calculate the total amount from complete weeks using the arithmetic progression formula.

4. Calculate the amount for the remaining days.

5. Return the total.

---

## 💻 C++ Solution

```cpp
class Solution {
public:
    int totalMoney(int n) {
        int weeks = n / 7;
        int days = n % 7;

        // Total money from complete weeks
        int total = weeks * (28 + (28 + (weeks - 1) * 7)) / 2;

        // Money from remaining days
        for (int i = 1; i <= days; i++) {
            total += weeks + i;
        }

        return total;
    }
};
```

## 🚀 Alternative Simple Approach

We can also simulate the deposits day by day.

```cpp
class Solution {
public:
    int totalMoney(int n) {
        int total = 0;
        int monday = 1;

        for (int day = 0; day < n; day++) {
            int currentDay = day % 7;

            total += monday + currentDay;

            if (currentDay == 6) {
                monday++;
            }
        }

        return total;
    }
};
```

This approach is easier to understand, while the mathematical approach directly uses the weekly pattern.
