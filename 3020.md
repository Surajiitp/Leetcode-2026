# 3020. Find the Maximum Number of Elements in Subset

## Problem Statement

You are given an integer array `nums`.

Find the maximum possible size of a subset that can be arranged in the form:

x, x, x², x², x⁴, x⁴, ...

where every number except the last appears exactly twice.

Return the maximum possible subset size.

**LeetCode Link:** https://leetcode.com/problems/find-the-maximum-number-of-elements-in-subset/

---

## Example 1

**Input**

```text
nums = [5,4,1,2,2]
```

**Output**

```text
1
```

---

## Example 2

**Input**

```text
nums = [1,1,1,1,1]
```

**Output**

```text
5
```

---

## Intuition

For every starting number:

- We need two copies of the current value.
- Then move to its square.
- Continue while every value appears at least twice.
- The last value may appear only once.

The answer is always an odd number.

---

## Algorithm

1. Count frequency of every number.
2. Handle `1` separately.
3. For every unique number:
   - Keep moving to its square.
   - Add `2` while frequency ≥ 2.
   - Add one more if the final value exists once.
4. Return the maximum length.

---

## C++ Solution

```cpp
class Solution {
public:
    int maximumLength(vector<int>& nums) {
        unordered_map<long long, int> freq;

        for (int x : nums)
            freq[x]++;

        int ans = 0;

        if (freq.count(1))
            ans = freq[1] % 2 ? freq[1] : freq[1] - 1;

        for (auto &[num, cnt] : freq) {
            if (num == 1)
                continue;

            long long x = num;
            int len = 0;

            while (freq[x] >= 2) {
                len += 2;
                x = x * x;

                if (x > 1e18)
                    break;
            }

            if (freq[x] == 1)
                len++;
            else
                len--;

            ans = max(ans, len);
        }

        return ans;
    }
};
```
