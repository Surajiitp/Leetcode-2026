3754. Concatenate Non-Zero Digits and Multiply by Sum I

Problem Statement

Given an integer "n", remove all "0" digits while preserving the order of the remaining digits to form a new number. Compute the sum of all non-zero digits and return the product of the new number and the sum.

Approach

- Traverse each digit of "n".
- Ignore any digit equal to "0".
- Construct a new number using only the non-zero digits while maintaining their original order.
- Simultaneously calculate the sum of the non-zero digits.
- Return the product of the constructed number and the computed sum.

C++ Solution

class Solution {
public:
    long long sumAndMultiply(int n) {
        int place = 1;
        long long x = 0;
        int sum = 0;

        while (n > 0) {
            int digit = n % 10;

            if (digit != 0) {
                x += 1LL * digit * place;
                place *= 10;
                sum += digit;
            }

            n /= 10;
        }

        return x * sum;
    }
};

Complexity Analysis

- Time Complexity: "O(log n)"
- Space Complexity: "O(1)"

Key Idea

- Skip all "0" digits.
- Build the new number using only non-zero digits.
- Keep track of the sum of non-zero digits during the same traversal.
- Multiply the constructed number by the sum to obtain the final answer.
