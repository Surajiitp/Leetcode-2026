## Problem Statement

Given a string `s` containing just the characters:

```text
'(', ')', '{', '}', '[' and ']'
```

Determine if the input string is valid.

A string is valid if:

1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

---

# Examples

## Example 1

```text
Input: s = "()"

Output: true
```

---

## Example 2

```text
Input: s = "()[]{}"

Output: true
```

---

## Example 3

```text
Input: s = "(]"

Output: false
```

---

## Example 4

```text
Input: s = "([])"

Output: true
```

---

## Example 5

```text
Input: s = "([)]"

Output: false
```

---

# Constraints

```text
1 <= s.length <= 10^4

s consists of parentheses only:
'(', ')', '{', '}', '[' and ']'
```

---

# Intuition

We need to check whether:

- every opening bracket has a matching closing bracket
- brackets close in the correct order

A **stack** is perfect for this problem because:

- opening brackets are pushed
- closing brackets are matched with the top element

---

# Approach

## Step-by-Step

### 1. Traverse the string

For every character:

- If opening bracket:
  - push into stack

- Else (closing bracket):
  - if stack empty → invalid
  - check top element
  - if matching:
    - pop
  - otherwise:
    - return false

---

### 2. Final Check

At the end:

- if stack is empty → valid
- otherwise → invalid

---

# Dry Run

## Input

```text
s = "([])"
```

---

## Execution

| Character | Stack | Operation |
|----------|-------|------------|
| `(` | `(` | push |
| `[` | `([` | push |
| `]` | `(` | pop |
| `)` | empty | pop |

Final stack becomes empty ✅

Answer = `true`

---

# C++ Solution

```cpp
class Solution {
public:
    bool isValid(string s) {

        stack<char> st;

        for(char ch : s) {

            // opening brackets
            if(ch == '(' || ch == '{' || ch == '[') {
                st.push(ch);
            }

            else {

                // stack empty
                if(st.empty()) {
                    return false;
                }

                // matching check
                if((st.top() == '(' && ch == ')') ||
                   (st.top() == '{' && ch == '}') ||
                   (st.top() == '[' && ch == ']')) {

                    st.pop();
                }
                else {
                    return false;
                }
            }
        }

        return st.empty();
    }
};
```

---

# Time Complexity

```text
O(n)
```

Because we traverse the string once.

---

# Space Complexity

```text
O(n)
```

In the worst case, all opening brackets are stored in stack.

# Key Concepts Used

- Stack
- String Traversal
- Matching Parentheses
- LIFO (Last In First Out)

---

# Why Stack Works Here?

Stack follows:

```text
Last In → First Out
```

The most recently opened bracket must close first.

Example:

```text
([{}])
```

`{` closes first, then `[`, then `(`.

This behavior perfectly matches stack operations.

# Edge Cases

## Case 1

```text
Input: "("
Output: false
```

Reason:
Opening bracket never closed.

---

## Case 2

```text
Input: ")"
Output: false
```

Reason:
Closing bracket without opening bracket.

---

## Case 3

```text
Input: "((()))"
Output: true
```

All brackets properly matched.
