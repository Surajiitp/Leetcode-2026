LeetCode 136 --- Single Number

Problem

Given a non-empty array of integers nums, every element appears
twice except for one element. Find that single element.

Requirements

Linear runtime: O(n)

Constant extra space: O(1)

Approach --- XOR

Use the XOR (^) operator.

Important XOR properties:

a ^ a = 0

a ^ 0 = a

XOR is commutative and associative.

Therefore, when every duplicate number is XORed together, the duplicate
pairs cancel out and only the single number remains.

Example

nums = [4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4

C++ Solution

class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int ans = 0;

        for (int i = 0; i < nums.size(); i++) {
            ans = ans ^ nums[i];
        }

        return ans;
    }
};

Complexity

Time: O(n)

Space: O(1)

Key Takeaway

When every number appears exactly twice except one, XOR is the optimal
solution because duplicate values cancel each other automatically.
