# 233. Number of Digit One

## Problem Statement

Given an integer `n`, count the total number of digit `'1'` appearing in all non-negative integers less than or equal to `n`.

---

## Example 1

**Input:**
```text
n = 13
```

**Output:**
```text
6
```

**Explanation:**

Numbers containing digit `1` from `0` to `13`:

```text
1, 10, 11, 12, 13
```

Total occurrences of digit `1` = **6**.

---

## Example 2

**Input:**

```text
n = 0
```

**Output:**

```text
0
```

---

## Intuition

Instead of checking every number from `1` to `n`, we count how many times digit `1` appears at each position independently.

For every digit position (`1`, `10`, `100`, ...):

- `left` = digits on the left side
- `cur` = current digit
- `right` = digits on the right side

### Cases

#### Case 1: `cur == 0`

Current position contributes:

```cpp
left * pos
```

#### Case 2: `cur == 1`

Current position contributes:

```cpp
left * pos + right + 1
```

#### Case 3: `cur > 1`

Current position contributes:

```cpp
(left + 1) * pos
```

Add contributions of all positions.

---

## Approach

1. Traverse each digit position (`1, 10, 100, ...`).
2. Calculate:
   - Left part
   - Current digit
   - Right part
3. Apply the above three cases.
4. Sum all contributions.
5. Return the answer.

---

## C++ Solution

```cpp
class Solution {
public:
    int countDigitOne(int n) {
        long long ans = 0;

        for (long long pos = 1; pos <= n; pos *= 10) {
            long long left = n / (pos * 10);
            long long cur = (n / pos) % 10;
            long long right = n % pos;

            if (cur == 0) {
                ans += left * pos;
            }
            else if (cur == 1) {
                ans += left * pos + right + 1;
            }
            else {
                ans += (left + 1) * pos;
            }
        }

        return ans;
    }
};
```

---

## Dry Run

### Input

```text
n = 13
```

### Position = 1

```text
left = 1
cur = 3
right = 0
```

Since `cur > 1`:

```text
Count = (1 + 1) × 1 = 2
```

### Position = 10

```text
left = 0
cur = 1
right = 3
```

Since `cur == 1`:

```text
Count = 0 × 10 + 3 + 1 = 4
```

### Total

```text
2 + 4 = 6
```

Answer = **6**

---

## Complexity Analysis

### Time Complexity

```text
O(log10(n))
```

Only one iteration per digit.

### Space Complexity

```text
O(1)
```

No extra space used.

---

## Key Takeaway

Instead of iterating through every number from `1` to `n`, count the occurrences of digit `1` at each digit position separately. This reduces the complexity from **O(n)** to **O(log n)**.
