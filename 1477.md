LeetCode 1477 - Find Two Non-overlapping Sub-arrays Each With Target Sum

Problem

Given an array of positive integers "arr" and an integer "target", find two non-overlapping subarrays such that the sum of each subarray is equal to "target".

Return the minimum possible sum of the lengths of the two subarrays.

If it is impossible to find two such subarrays, return "-1".

---

Example

Input

arr = [3,2,2,4,3]
target = 3

Output

2

Explanation

The two non-overlapping subarrays are:

[3]       → length = 1
[3]       → length = 1

Therefore:

1 + 1 = 2

---

Approach

We use Sliding Window + Dynamic Programming.

Since all elements in the array are positive:

1. Maintain a sliding window using "left" and "right".
2. Calculate the current window sum.
3. If the sum becomes greater than "target", move "left" forward.
4. When the sum equals "target", we have found a valid subarray.
5. Store the minimum length of any valid subarray found so far in "dp".
6. For the current subarray, check whether a valid subarray exists completely before it.
7. Update the minimum combined length.

DP Definition

dp[i] = minimum length of a valid subarray
        found in the range [0 ... i]

For a valid subarray "[left ... right]":

answer = min(answer, currentLength + dp[left - 1])

This guarantees that the two subarrays do not overlap.

---

C++ Solution

class Solution {
public:
    int minSumOfLengths(vector<int>& arr, int target) {
        int n = arr.size();
        const int INF = 1e9;

        vector<int> dp(n, INF);

        int left = 0;
        int sum = 0;
        int best = INF;
        int ans = INF;

        for (int right = 0; right < n; right++) {
            sum += arr[right];

            while (sum > target) {
                sum -= arr[left++];
            }

            if (sum == target) {
                int len = right - left + 1;

                if (left > 0 && dp[left - 1] != INF) {
                    ans = min(ans, len + dp[left - 1]);
                }

                best = min(best, len);
            }

            dp[right] = best;
        }

        return ans == INF ? -1 : ans;
    }
};
