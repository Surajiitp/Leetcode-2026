# LeetCode 3720 - Lexicographically Smallest Permutation Greater Than Target

## Problem Description

Given two strings `s` and `target`, find the lexicographically smallest permutation of `s` that is strictly greater than `target`.

If no such permutation exists, return an empty string `""`.

---

## Approach

1. Sort the string `s`.
2. Try every position from right to left.
3. For each position, check whether the prefix of `target` can be created using characters from `s`.
4. At the current position, choose the smallest character that is greater than `target[i]`.
5. Fill the remaining positions with the available characters in ascending order.
6. Return the answer.
7. If no valid permutation exists, return `""`.

---

## C++ Solution

```cpp
class Solution {
public:
    string lexGreaterPermutation(string s, string target) {
        int n = s.size();

        sort(s.begin(), s.end());

        // Try every position from right to left
        for (int i = n - 1; i >= 0; i--) {
            string prefix = target.substr(0, i);

            // Check whether prefix can be made from s
            vector<int> cnt(26, 0);

            for (char c : s)
                cnt[c - 'a']++;

            bool possible = true;

            for (char c : prefix) {
                if (cnt[c - 'a'] == 0) {
                    possible = false;
                    break;
                }

                cnt[c - 'a']--;
            }

            if (!possible)
                continue;

            // At position i, choose the smallest character
            // greater than target[i]
            for (int c = target[i] - 'a' + 1; c < 26; c++) {

                if (cnt[c] > 0) {
                    string ans = prefix;

                    ans += char('a' + c);
                    cnt[c]--;

                    // Fill remaining characters in ascending order
                    for (int j = 0; j < 26; j++) {
                        while (cnt[j] > 0) {
                            ans += char('a' + j);
                            cnt[j]--;
                        }
                    }

                    return ans;
                }
            }
        }

        return "";
    }
};
