# LeetCode 1621 - Number of Sets of K Non-Overlapping Line Segments

## 📝 Problem

Given `n` points on a 1D coordinate plane numbered from `0` to `n - 1`, find the number of ways to draw `k` **non-overlapping line segments**.

A segment must have:

* Its endpoints at two different points.
* No two segments should overlap.
* Segments are allowed to share endpoints.

Return the answer modulo `10^9 + 7`.

---

## 💡 Approach

We use **Dynamic Programming**.

Let:

```text
dp[i][j]
```

represent the number of ways to choose `j` non-overlapping segments using the first `i` points.

For every new point, we have two choices:

1. **Do not use the point to create a new segment.**
2. **Use it as the endpoint of a segment.**

A more optimized DP formulation keeps track of whether we are currently extending a segment.

The recurrence can be optimized to **O(n × k)** time.

---

## 🚀 C++ Solution

```cpp
class Solution {
public:
    int numberOfSets(int n, int k) {
        const int MOD = 1e9 + 7;

        vector<vector<long long>> dp(k + 1, vector<long long>(n, 0));

        // 0 segments can always be formed in one way.
        for (int i = 0; i < n; i++) {
            dp[0][i] = 1;
        }

        for (int segments = 1; segments <= k; segments++) {
            long long sum = 0;

            for (int points = 1; points < n; points++) {
                sum = (sum + dp[segments - 1][points - 1]) % MOD;
                dp[segments][points] =
                    (dp[segments][points - 1] + sum) % MOD;
            }
        }

        return dp[k][n - 1];
    }
};
```

## 🔍 Example

### Input

```text
n = 4
k = 2
```

Points:

```text
0  1  2  3
```

We need to select 2 non-overlapping segments.

The answer is:

```text
3
```

## ⏱️ Complexity

* **Time:** `O(n × k)`
* **Space:** `O(n × k)`

---

## 🔑 Key Concept

This problem is a good example of:

* Dynamic Programming
* Prefix Sum Optimization
* Counting Combinations
* Non-overlapping Intervals

### Important Observation

Segments are allowed to **share endpoints**, but their interiors cannot overlap.

For example:

```text
0 ---- 1 ---- 2 ---- 3

[0,1] and [1,3]
```

These segments are valid because they only share the endpoint `1`.
