# LeetCode 3689 - Maximum Total Subarray Value I

## Problem Statement

Given an integer array `nums` and an integer `k`, the value of a subarray is defined as:

```text
max(subarray) - min(subarray)
```

You can choose the same subarray multiple times. Find the maximum total value obtainable after choosing exactly `k` subarrays.

---

## Approach

To maximize the total value, we need the subarray with the largest possible value.

The maximum value of any subarray is obtained by taking the entire array, which gives:

```text
max(nums) - min(nums)
```

Since the same subarray can be selected multiple times, choose this optimal subarray `k` times.

Therefore:

```text
Answer = (max(nums) - min(nums)) × k
```

---

## C++ Solution

```cpp
class Solution {
public:
    long long maxTotalValue(vector<int>& nums, int k) {
        long long mn = nums[0];
        long long mx = nums[0];

        for (int num : nums) {
            mn = min(mn, (long long)num);
            mx = max(mx, (long long)num);
        }

        return (mx - mn) * k;
    }
};
```

---

## Example

### Input

```text
nums = [4, 2, 5, 1]
k = 3
```

### Calculation

```text
max(nums) = 5
min(nums) = 1

Value = 5 - 1 = 4
Total = 4 × 3 = 12
```

### Output

```text
12
```

---

## Complexity Analysis

* Time Complexity: **O(n)**
* Space Complexity: **O(1)**

---

The maximum possible subarray value is simply the difference between the largest and smallest elements in the array. Since the same subarray may be chosen multiple times, multiplying this value by `k` gives the maximum total value.
