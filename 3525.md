# LeetCode 3525 — Find X Value of Array II

**Difficulty:** Hard
**Language:** C++
**Data Structure:** Segment Tree

## Problem

Given an array `nums`, an integer `k`, and multiple queries.

Each query:

```text
[index, value, start, x]
```

requires us to:

1. Update `nums[index]` to `value`.
2. Consider the array from `start` to the end.
3. Count the prefixes whose product modulo `k` is equal to `x`.

Return the answer for every query.

---

## Approach

A simple approach would be too slow because every query can require scanning a large part of the array.

We use a **Segment Tree** with a small amount of information per node.

For every node we maintain:

```cpp
prod
```

The product of all elements in the segment modulo `k`.

And:

```cpp
cnt[r]
```

The number of prefixes having product modulo `k` equal to `r`.

Since `k <= 5`, each node only needs **5 counters**.

---

## Merge Operation

For two nodes `L` and `R`:

### Product

```cpp
res.prod = (L.prod * R.prod) % k;
```

### Prefixes from Left

All prefixes completely inside the left segment remain unchanged:

```cpp
res.cnt[r] += L.cnt[r];
```

### Prefixes extending into Right

If a prefix of the right segment has remainder `r`, its new remainder becomes:

```cpp
(L.prod * r) % k
```

So:

```cpp
int nr = (L.prod * r) % k;
res.cnt[nr] += R.cnt[r];
```

---

## Point Update

For every query, the required index is updated:

```cpp
nums[index] = value;
```

The corresponding leaf is changed and all its ancestors are recalculated.

---

## Range Query

After updating, we query:

```text
[start, n)
```

The required answer is:

```cpp
res.cnt[x]
```

---

## Complexity

Let `N = nums.size()` and `Q = queries.size()`.

Since each merge takes `O(k)`:

| Operation | Complexity         |
| --------- | ------------------ |
| Build     | `O(N × k)`         |
| Update    | `O(k × log N)`     |
| Query     | `O(k × log N)`     |
| Total     | `O(Nk + Qk log N)` |
| Space     | `O(Nk)`            |

Because `k` is very small, the solution is efficient.

---

## C++ Solution

```cpp
class Solution {
public:
    struct Node {
        int prod;
        int cnt[5];

        Node() {
            prod = 1;
            for (int i = 0; i < 5; i++)
                cnt[i] = 0;
        }
    };

    int k;
    vector<Node> seg;

    Node mergeNode(const Node& L, const Node& R) {
        Node res;

        res.prod = (L.prod * R.prod) % k;

        for (int r = 0; r < k; r++) {
            res.cnt[r] += L.cnt[r];
        }

        for (int r = 0; r < k; r++) {
            int nr = (L.prod * r) % k;
            res.cnt[nr] += R.cnt[r];
        }

        return res;
    }

    Node query(int l, int r) {
        Node leftRes, rightRes;

        l += (int)seg.size() / 2;
        r += (int)seg.size() / 2;

        while (l < r) {
            if (l & 1) {
                leftRes = mergeNode(leftRes, seg[l]);
                l++;
            }

            if (r & 1) {
                --r;
                rightRes = mergeNode(seg[r], rightRes);
            }

            l >>= 1;
            r >>= 1;
        }

        return mergeNode(leftRes, rightRes);
    }

    vector<int> resultArray(
        vector<int>& nums,
        int K,
        vector<vector<int>>& queries
    ) {
        k = K;
        int n = nums.size();

        int size = 1;
        while (size < n)
            size <<= 1;

        seg.assign(2 * size, Node());

        for (int i = 0; i < n; i++) {
            int rem = nums[i] % k;

            seg[size + i].prod = rem;
            seg[size + i].cnt[rem] = 1;
        }

        for (int i = size - 1; i >= 1; i--) {
            seg[i] = mergeNode(
                seg[2 * i],
                seg[2 * i + 1]
            );
        }

        vector<int> ans;
        ans.reserve(queries.size());

        for (auto& q : queries) {
            int index = q[0];
            int value = q[1];
            int start = q[2];
            int x = q[3];

            int pos = size + index;

            seg[pos] = Node();

            int rem = value % k;

            seg[pos].prod = rem;
            seg[pos].cnt[rem] = 1;

            pos >>= 1;

            while (pos >= 1) {
                seg[pos] = mergeNode(
                    seg[2 * pos],
                    seg[2 * pos + 1]
                );

                pos >>= 1;
            }

            Node res = query(start, n);

            ans.push_back(res.cnt[x]);
        }

        return ans;
    }
};
```

---

## Key Takeaway

The main trick is to store **prefix-product remainders** in every Segment Tree node.

Because `k` is at most `5`, merging two nodes is extremely cheap.

> **Segment Tree + Modular Prefix Products = Efficient Dynamic Queries**
