2948. Make Lexicographically Smallest Array by Swapping Elements

📝 Problem Statement

You are given a 0-indexed array nums of positive integers and a positive integer limit.

In one operation, you can choose two indices i and j and swap nums[i] and nums[j] if:

|nums[i] - nums[j]| <= limit

You can perform the operation any number of times.

Return the lexicographically smallest array that can be obtained.

💡 Approach

The important observation is that if two values can be connected through a sequence of valid swaps, then all values in that connected group can be rearranged among their original positions.

Step 1: Sort the values

Store every value along with its original index:

pair<value, index>

Then sort these pairs by value.

Step 2: Find connected groups

After sorting, if the difference between two consecutive values is at most limit, they belong to the same group.

For example:

nums = [1, 5, 3, 9, 8]
limit = 2

Sorted:

(1,0), (3,2), (5,1), (8,4), (9,3)

Groups:

[1, 3, 5]     -> difference between consecutive values <= 2
[8, 9]        -> difference <= 2

Inside each group, we can place the smallest values at the smallest original indices to obtain the lexicographically smallest result.

Step 3: Sort indices inside each group

For every group:

Collect its original indices.

Sort those indices.

The values are already sorted.

Put the smallest value at the smallest index, the next smallest at the next index, and so on.

🔍 Example

Input

nums = [1,5,3,9,8]
limit = 2

Sorted value-index pairs:

(1,0), (3,2), (5,1), (8,4), (9,3)

Groups:

Group 1:
values = [1,3,5]
indices = [0,2,1] -> sorted = [0,1,2]

Group 2:
values = [8,9]
indices = [4,3] -> sorted = [3,4]

Place values according to sorted indices:

Index:  0 1 2 3 4
Value:  1 3 5 8 9

Therefore:

Output = [1,3,5,8,9]

💻 C++ Solution

class Solution {
public:
    vector<int> lexicographicallySmallestArray(vector<int>& nums, int limit) {
        int n = nums.size();

        // Store {value, original index}
        vector<pair<int, int>> arr;

        for (int i = 0; i < n; i++) {
            arr.push_back({nums[i], i});
        }

        // Sort by value
        sort(arr.begin(), arr.end());

        int i = 0;

        while (i < n) {
            int j = i;

            // Find one connected group
            while (j + 1 < n &&
                   arr[j + 1].first - arr[j].first <= limit) {
                j++;
            }

            // Collect original indices of this group
            vector<int> indices;

            for (int k = i; k <= j; k++) {
                indices.push_back(arr[k].second);
            }

            // Smallest values should go to smallest indices
            sort(indices.begin(), indices.end());

            for (int k = i; k <= j; k++) {
                nums[indices[k - i]] = arr[k].first;
            }

            i = j + 1;
        }

        return nums;
    }
};

⏱️ Complexity

Let n be the size of nums.

Sorting value-index pairs: O(n log n)

Sorting indices of all groups: O(n log n) in the worst case

Constructing the answer: O(n)

Overall

Time Complexity: O(n log n)
Space Complexity: O(n)

🎯 Key Insight

The main idea is:

Values connected through valid swaps form a group, and within each group we can freely rearrange the values among their original indices.

To make the array lexicographically smallest:

Smallest values → Smallest available indices
