# 3737. Count Subarrays With Majority Element I

## 📝 Problem Statement

Given an integer array `nums` and an integer `target`, return the number of subarrays in which `target` is the **majority element**.

A majority element in a subarray is an element that appears **more than half** of the subarray's length.

**LeetCode Link:** https://leetcode.com/problems/count-subarrays-with-majority-element-i/

---

## 💡 Approach

We use a **Brute Force** approach.

- Iterate over every possible starting index.
- Extend the subarray one element at a time.
- Maintain the frequency of each element using an `unordered_map`.
- For every subarray, check if the frequency of `target` is greater than half of the subarray length.
- If yes, increment the answer.

Since the constraints are small (`n <= 1000`), an **O(n²)** solution is sufficient.

---

## ⚙️ Algorithm

1. Initialize `answer = 0`.
2. For every starting index `i`:
   - Create an empty frequency map.
   - Traverse from `j = i` to `n - 1`.
   - Update the frequency of `nums[j]`.
   - Compute the current subarray length.
   - If `freq[target] > length / 2`, increment the answer.
3. Return the answer.

---

## ✅ C++ Solution

```cpp
class Solution {
public:
    int countMajoritySubarrays(vector<int>& nums, int target) {
        int n = nums.size();
        int ans = 0;

        for (int i = 0; i < n; i++) {
            unordered_map<int, int> cnt;

            for (int j = i; j < n; j++) {
                cnt[nums[j]]++;

                int len = j - i + 1;

                if (cnt[target] > len / 2)
                    ans++;
            }
        }

        return ans;
    }
};
```

- **Time Complexity:** `O(n²)`
- **Space Complexity:** `O(n)`

This problem demonstrates how frequency counting can efficiently determine whether a specific element is the majority within every possible subarray. Given the small constraints, the quadratic solution is both simple and effective.
