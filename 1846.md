# 1846. Maximum Element After Decreasing and Rearranging

## Problem Statement

You are given an array `arr` of positive integers.

You may perform the following operations any number of times:

- Rearrange the elements.
- Decrease the value of any element to any smaller positive integer.

After performing the operations, the array must satisfy:

- The first element is `1`.
- The absolute difference between adjacent elements is at most `1`.

Return the maximum possible value of the largest element.

**LeetCode Link:** https://leetcode.com/problems/maximum-element-after-decreasing-and-rearranging/

---

## Example 1

**Input**

```text
arr = [2,2,1,2,1]
```

**Output**

```text
2
```

---

## Example 2

**Input**

```text
arr = [100,1,1000]
```

**Output**

```text
3
```

---

## Intuition

To maximize the largest element:

- Sort the array.
- Force the first element to be `1`.
- Every next element can be at most `previous + 1`.
- If it is larger, decrease it.

This greedy strategy always produces the largest possible final element.

---

## Algorithm

1. Sort the array.
2. Set `arr[0] = 1`.
3. Traverse from left to right:
   - `arr[i] = min(arr[i], arr[i - 1] + 1)`
4. Return the last element.

---

## C++ Solution

```cpp
class Solution {
public:
    int maximumElementAfterDecrementingAndRearranging(vector<int>& arr) {
        sort(arr.begin(), arr.end());

        arr[0] = 1;

        for (int i = 1; i < arr.size(); i++) {
            arr[i] = min(arr[i], arr[i - 1] + 1);
        }

        return arr.back();
    }
};
```

## Complexity Analysis

- **Time Complexity:** `O(n log n)`
- **Space Complexity:** `O(1)` (excluding sorting)

---

## Why This Works

- Sorting ensures elements are processed in increasing order.
- Keeping each element at most `previous + 1` satisfies the adjacent difference constraint.
- Greedily choosing the largest valid value maximizes the final element.
