# Count Nodes Equal to Average of Subtree

## 📝 Problem Statement

Given the root of a binary tree, return the number of nodes where the value of the node is equal to the **average of the values in its subtree**.

The average is calculated as:

```text
average = sum of values in subtree / number of nodes in subtree
```

The result is **rounded down** to the nearest integer.

A subtree includes the current node and **all of its descendants**.

---

## 💡 Example 1

### Input

```text
root = [4,8,5,0,1,null,6]
```

### Binary Tree

```text
        4
       / \
      8   5
     / \   \
    0   1   6
```

### Output

```text
5
```

### Explanation

* Node `4` → `(4 + 8 + 5 + 0 + 1 + 6) / 6 = 4` ✅
* Node `8` → `(8 + 0 + 1) / 3 = 3` ❌
* Node `5` → `(5 + 6) / 2 = 5` ✅
* Node `0` → `0 / 1 = 0` ✅
* Node `1` → `1 / 1 = 1` ✅
* Node `6` → `6 / 1 = 6` ✅

Therefore:

```text
Answer = 5
```

---

## 💡 Example 2

### Input

```text
root = [1]
```

### Output

```text
1
```

### Explanation

The subtree contains only node `1`.

```text
average = 1 / 1 = 1
```

Therefore, node `1` is counted.

---

## 🚀 Approach

We use **Depth First Search (DFS)** with **postorder traversal**.

For every node, we calculate two things:

1. **Sum** of all values in its subtree.
2. **Count** of nodes in its subtree.

After getting the information from the left and right subtrees:

```text
sum = leftSum + rightSum + root->val
count = leftCount + rightCount + 1
```

Then calculate:

```text
average = sum / count
```

If:

```text
root->val == average
```

we increment our answer.

### Why Postorder DFS?

We need the sum and count of the left and right subtrees before we can calculate the sum and count for the current node.

So the traversal order is:

```text
Left → Right → Root
```

---

## 💻 C++ Solution

```cpp
class Solution {
public:
    int ans = 0;

    // Returns {sum, count} of the subtree
    pair<int, int> dfs(TreeNode* root) {
        if (root == nullptr)
            return {0, 0};

        // Get information from left and right subtrees
        auto left = dfs(root->left);
        auto right = dfs(root->right);

        // Calculate sum and count for current subtree
        int sum = root->val + left.first + right.first;
        int count = 1 + left.second + right.second;

        // Check if node value equals subtree average
        if (root->val == sum / count)
            ans++;

        return {sum, count};
    }

    int averageOfSubtree(TreeNode* root) {
        dfs(root);
        return ans;
    }
};
```

## 🔍 Dry Run

Consider:

```text
        5
         \
          6
```

For node `6`:

```text
sum = 6
count = 1
average = 6 / 1 = 6
```

So:

```text
6 == 6 → count = 1
```

For node `5`:

```text
sum = 5 + 6 = 11
count = 2

average = 11 / 2 = 5
```

So:

```text
5 == 5 → count = 2
```

Both nodes are counted.

## ⏱️ Complexity Analysis

### Time Complexity

```text
O(n)
```

Each node is visited exactly once.

### Space Complexity

```text
O(h)
```

where `h` is the height of the binary tree, due to the recursive call stack.

For a balanced tree:

```text
O(log n)
```

For a completely skewed tree:

```text
O(n)
```

## ⭐ Takeaway

The important trick is to return **both the subtree sum and subtree node count** from every recursive call.

```text
        Node
       /    \
   {sum,cnt} {sum,cnt}
        ↓
   {totalSum,totalCount}
        ↓
      average
        ↓
   Check node value
```

This allows us to solve the problem efficiently in **O(n)** time.
