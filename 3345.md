# 3345. Smallest Divisible Digit Product I

## 🟢 Easy

### 📖 Problem Statement

Given two integers `n` and `t`, find the smallest integer greater than or equal to `n` such that the product of its digits is divisible by `t`.

Return that smallest integer.

---

## 💡 Approach

- Start checking numbers from `n`.
- For each number:
  - Calculate the product of all its digits.
  - Check whether the product is divisible by `t`.
- If divisible, return the current number.
- Otherwise, increment the number and repeat.

Since the constraints are small, a brute-force solution is sufficient.

---

## ✅ Algorithm

1. Initialize the current number as `n`.
2. Compute the product of its digits.
3. If `product % t == 0`, return the current number.
4. Otherwise, increment the number.
5. Repeat until the answer is found.

---

## 💻 C++ Solution

```cpp
class Solution {
public:
    int smallestNumber(int n, int t) {
        while (true) {
            int x = n;
            int product = 1;

            while (x > 0) {
                product *= (x % 10);
                x /= 10;
            }

            if (product % t == 0)
                return n;

            n++;
        }
    }
};
```

---

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(k × d)`
  - `k` = numbers checked until the answer is found
  - `d` = number of digits in the number

- **Space Complexity:** `O(1)`
