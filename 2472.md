# LeetCode 2472 - Maximum Number of Non-overlapping Palindrome Substrings

## Problem

Given a string `s` and an integer `k`, find the maximum number of non-overlapping palindromic substrings of `s` such that each palindrome has a length of at least `k`.

## Approach

We use **Dynamic Programming + Expand Around Center**.

* `dp[i]` represents the maximum number of valid non-overlapping palindromes using the first `i` characters.
* For every index, we check both:

  * Odd-length palindromes
  * Even-length palindromes
* We expand around each possible center to find palindromic substrings.
* If the palindrome length is at least `k`, we update the DP:
  `dp[r + 1] = max(dp[r + 1], dp[l] + 1)`
* We also carry forward the previous answer when we don't select a palindrome ending at the current position.

## C++ Solution

```cpp
class Solution {
public:
    int maxPalindromes(string s, int k) {
        int n = s.size();

        vector<int> dp(n + 1, 0);

        for (int i = 0; i < n; i++) {

            // Don't choose a palindrome ending here
            dp[i + 1] = max(dp[i + 1], dp[i]);

            // Odd-length palindrome
            int l = i, r = i;

            while (l >= 0 && r < n && s[l] == s[r]) {

                if (r - l + 1 >= k) {
                    dp[r + 1] = max(dp[r + 1], dp[l] + 1);
                }

                l--;
                r++;
            }

            // Even-length palindrome
            l = i;
            r = i + 1;

            while (l >= 0 && r < n && s[l] == s[r]) {

                if (r - l + 1 >= k) {
                    dp[r + 1] = max(dp[r + 1], dp[l] + 1);
                }

                l--;
                r++;
            }
        }

        return dp[n];
    }
};
```

## Example

### Input

```text
s = "abaccdbbd"
k = 3
```

### Output

```text
2
```

### Explanation

We can select two non-overlapping palindromic substrings whose lengths are at least `3`.

Therefore, the maximum number of valid palindromic substrings is:

```text
2
```

## Complexity

* **Time Complexity:** `O(n²)`
* **Space Complexity:** `O(n)`

## Key Concepts

* Dynamic Programming
* Palindrome Checking
* Expand Around Center
* Non-overlapping Intervals
* String Manipulation

## Important DP Transition

For a palindrome from index `l` to `r`:

```cpp
dp[r + 1] = max(dp[r + 1], dp[l] + 1);
```

Here:

* `dp[l]` → best answer before the palindrome starts
* `+1` → select the current palindrome
* `dp[r + 1]` → best answer after including the current palindrome
