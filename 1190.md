# 🔄 LeetCode 1190 — Reverse Substrings Between Each Pair of Parentheses

## 📝 Problem Statement

Given a string `s` containing lowercase English letters and parentheses, reverse the strings inside each matching pair of parentheses.

The parentheses themselves should not appear in the final answer.

If parentheses are nested, reverse the innermost substring first and continue outward.

### Example

**Input:**

```text
s = "(u(love)i)"
```

**Output:**

```text
"iloveu"
```

---

## 💡 Approach

We use a **matching-parentheses + direction reversal** technique.

### Steps

1. Use a stack to find the matching index of every parenthesis.
2. Store the matching positions in an array `pair`.
3. Traverse the string from left to right.
4. Whenever a parenthesis is encountered:

   * Jump directly to its matching parenthesis.
   * Reverse the traversal direction.
5. Add only normal characters to the answer.
6. Since every pair of parentheses changes the direction, nested reversals are handled automatically.

---

## 🔍 Example Walkthrough

For:

```text
(u(love)i)
```

The matching pairs are:

```text
0 ↔ 9
2 ↔ 7
```

When we encounter `(` or `)`:

```cpp
i = pair[i];
dir = -dir;
```

The traversal direction changes.

This allows us to read characters in the required reversed order **without actually reversing substrings**.

---

## 💻 C++ Solution

```cpp
class Solution {
public:
    string reverseParentheses(string s) {
        int n = s.size();

        // pair[i] = matching bracket index
        vector<int> pair(n);
        stack<int> st;

        // Find matching parentheses
        for (int i = 0; i < n; i++) {
            if (s[i] == '(') {
                st.push(i);
            }
            else if (s[i] == ')') {
                int j = st.top();
                st.pop();

                pair[i] = j;
                pair[j] = i;
            }
        }

        string ans;

        int i = 0;
        int dir = 1;

        while (i < n) {

            // Jump to matching bracket
            if (s[i] == '(' || s[i] == ')') {
                i = pair[i];
                dir = -dir;
            }
            else {
                ans += s[i];
            }

            i += dir;
        }

        return ans;
    }
};
```

---

## ⏱️ Complexity Analysis

Let `n` be the length of the string.

### Time Complexity

```text
O(n)
```

Each character and parenthesis is processed a constant number of times.

### Space Complexity

```text
O(n)
```

We use:

* `pair` array → `O(n)`
* Stack → `O(n)`
* Answer string → `O(n)`

---

## 🚀 Key Concept

The important trick is:

```cpp
i = pair[i];
dir = -dir;
```

Instead of physically reversing a substring, we **change the traversal direction**.

This makes the solution efficient and avoids repeated string reversals.
