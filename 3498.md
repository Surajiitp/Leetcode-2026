# LeetCode 3498 - Reverse Degree of a String

## Problem

Given a string `s`, calculate its **reverse degree**.

For every character:

* Find its position in the **reversed alphabet**:

  * `a = 26`
  * `b = 25`
  * `c = 24`
  * ...
  * `z = 1`
* Multiply this value by the character's **1-indexed position** in the string.
* Add all the products.

Return the total reverse degree.

---

## Example

### Input

```text
s = "abc"
```

### Calculation

| Character | Reverse Alphabet Value | Position | Product |
| --------- | ---------------------- | -------- | ------- |
| `a`       | 26                     | 1        | 26      |
| `b`       | 25                     | 2        | 50      |
| `c`       | 24                     | 3        | 72      |

### Output

```text
148
```

Because:

```text
26 + 50 + 72 = 148
```

---

## Approach

For each character `s[i]`:

```cpp
int rev = 26 - (s[i] - 'a');
```

### Why does this work?

Normally:

```text
a -> 0
b -> 1
c -> 2
...
z -> 25
```

So the reversed alphabet position is:

```text
26 - (s[i] - 'a')
```

For example:

```text
'a' -> 26 - 0  = 26
'b' -> 26 - 1  = 25
'c' -> 26 - 2  = 24
'z' -> 26 - 25 = 1
```

Then multiply it by the 1-indexed position:

```cpp
ans += rev * (i + 1);
```

---

## C++ Solution

```cpp
class Solution {
public:
    int reverseDegree(string s) {
        int ans = 0;

        for (int i = 0; i < s.size(); i++) {
            int rev = 26 - (s[i] - 'a');
            ans += rev * (i + 1);
        }

        return ans;
    }
};
```

---

## Complexity

### Time Complexity

```text
O(n)
```

We iterate through the string once.

### Space Complexity

```text
O(1)
```

Only a few integer variables are used.

## Example 2

### Input

```text
s = "zaza"
```

### Calculation

```text
z -> 1 × 1 = 1
a -> 26 × 2 = 52
z -> 1 × 3 = 3
a -> 26 × 4 = 104
```

Therefore:

```text
1 + 52 + 3 + 104 = 160
```

### Output

```text
160
```

---

## Key Concept

The main trick is:

```cpp
26 - (s[i] - 'a')
```

This directly converts a lowercase character into its **reverse alphabet position**.
