# Smallest Missing Multiple of K

## Problem

Given an integer array `nums` and an integer `k`, return the smallest positive multiple of `k` that is missing from `nums`.

A multiple of `k` is any positive integer divisible by `k`.

### Examples

**Example 1**
```
Input:  nums = [8,2,3,4,6], k = 2
Output: 10
Explanation: The multiples of k = 2 are 2, 4, 6, 8, 10, 12...
             The smallest multiple missing from nums is 10.
```

**Example 2**
```
Input:  nums = [1,4,7,10,15], k = 5
Output: 5
Explanation: The multiples of k = 5 are 5, 10, 15, 20...
             The smallest multiple missing from nums is 5.
```

### Constraints

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
- `1 <= k <= 100`

---

## Approach

1. Dump all of `nums` into a hash set for O(1) lookups.
2. Walk through the multiples of `k` in order — `k, 2k, 3k, ...`
3. Return the first multiple not present in the set.

Since `nums[i] <= 100`, the answer is found quickly: at most `101` multiples of `k` need to be checked before hitting one guaranteed to be absent from `nums` (as `nums` has at most 100 elements).

### Complexity

- **Time:** O(n + m), where `n = nums.size()` and `m` is the number of multiples checked (bounded by ~`nums.size() + 1` in the worst case).
- **Space:** O(n) for the hash set.

---

## Solution (C++)

```cpp
class Solution {
public:
    int missingMultiple(vector<int>& nums, int k) {
        unordered_set<int> st;

        // Store all elements
        for (int x : nums) {
            st.insert(x);
        }

        // Check k, 2k, 3k, ...
        for (int i = 1; ; i++) {
            int multiple = i * k;

            if (st.find(multiple) == st.end()) {
                return multiple;
            }
        }
    }
};
```

### Walkthrough — Example 1

```
nums = {8, 2, 3, 4, 6}, k = 2
i=1 -> multiple=2  -> in set, skip
i=2 -> multiple=4  -> in set, skip
i=3 -> multiple=6  -> in set, skip
i=4 -> multiple=8  -> in set, skip
i=5 -> multiple=10 -> NOT in set -> return 10
```
