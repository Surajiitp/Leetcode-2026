LeetCode 2091 - Removing Minimum and Maximum From Array

📝 Problem Statement

You are given an integer array "nums".

You need to remove both the minimum and maximum elements from the array.

In one operation, you can remove an element from either:

- The beginning (left) of the array
- The end (right) of the array

Return the minimum number of deletions required to remove both the minimum and maximum elements.

Example

Input:

nums = [2,10,7,5,4,1,8,6]

Output:

5

---

💡 Approach

First, find the indices of the minimum and maximum elements.

Let:

- "minIdx" = index of minimum element
- "maxIdx" = index of maximum element

To remove both elements, there are only three possible strategies.

1. Remove both elements from the left

We remove elements from the beginning until we reach the element with the larger index.

fromLeft = maxIdx + 1;

---

2. Remove both elements from the right

We remove elements from the end until we remove the element with the smaller index.

fromRight = n - minIdx;

---

3. Remove one element from each side

Remove the element with the smaller index from the left and the other element from the right.

bothSides = (minIdx + 1) + (n - maxIdx);

Finally, return the minimum among these three possibilities.

return min({fromLeft, fromRight, bothSides});

---

🔍 Important Observation

After finding the indices, we make sure:

minIdx < maxIdx

If not, we swap them:

if (minIdx > maxIdx)
    swap(minIdx, maxIdx);

This makes the calculations easier.

---

💻 C++ Solution

class Solution {
public:
    int minimumDeletions(vector<int>& nums) {
        int n = nums.size();

        int minIdx = 0, maxIdx = 0;

        // Find indices of minimum and maximum
        for (int i = 0; i < n; i++) {
            if (nums[i] < nums[minIdx])
                minIdx = i;

            if (nums[i] > nums[maxIdx])
                maxIdx = i;
        }

        // Make minIdx the smaller index
        if (minIdx > maxIdx)
            swap(minIdx, maxIdx);

        // Three possibilities:
        // 1. Delete both from the left
        // 2. Delete min from left and max from right
        // 3. Delete both from the right

        int fromLeft = maxIdx + 1;
        int fromRight = n - minIdx;
        int bothSides = (minIdx + 1) + (n - maxIdx);

        return min({fromLeft, fromRight, bothSides});
    }
};

---

⏱️ Complexity

Time Complexity

O(n)

We traverse the array once to find the minimum and maximum indices.

Space Complexity

O(1)

Only a few variables are used.

---

✅ Key Takeaway

The problem can be reduced to checking just three possibilities:

1. Both from left
2. Both from right
3. One from left + one from right

The minimum of these three gives the optimal answer.
