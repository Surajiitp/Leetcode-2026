LeetCode 115 - Distinct Subsequences

Problem Statement

Given two strings "s" and "t", return the number of distinct subsequences of "s" which equals "t".

A subsequence is a string that can be obtained by deleting some (possibly none) of the characters of the original string without changing the order of the remaining characters.

Example

Input:

s = "rabbbit"
t = "rabbit"

Output:

3

Explanation

There are 3 distinct ways to form ""rabbit"" from ""rabbbit"" by deleting one of the three "'b'" characters.

---

Approach

We use Dynamic Programming (DP).

Let:

dp[i][j]

represent the number of distinct subsequences of the first "i" characters of "s" that form the first "j" characters of "t".

DP Transitions

If:

s[i - 1] == t[j - 1]

we have two choices:

1. Use "s[i-1]" to match "t[j-1]"
2. Skip "s[i-1]"

Therefore:

dp[i][j] = dp[i-1][j-1] + dp[i-1][j]

If the characters are different, we cannot use "s[i-1]":

dp[i][j] = dp[i-1][j]

---

Base Cases

Empty target

An empty string can always be formed by deleting all characters:

dp[i][0] = 1

Empty source

If "s" is empty and "t" is not empty:

dp[0][j] = 0

---

C++ Solution

class Solution {
public:
    int numDistinct(string s, string t) {
        int n = s.size();
        int m = t.size();

        vector<vector<unsigned long long>> dp(
            n + 1,
            vector<unsigned long long>(m + 1, 0)
        );

        // Empty target can be formed in exactly one way
        dp[0][0] = 1;

        for (int i = 1; i <= n; i++) {
            dp[i][0] = 1;

            for (int j = 1; j <= m; j++) {

                // Skip s[i-1]
                dp[i][j] = dp[i - 1][j];

                // Use s[i-1] if characters match
                if (s[i - 1] == t[j - 1]) {
                    dp[i][j] += dp[i - 1][j - 1];
                }
            }
        }

        return dp[n][m];
    }
};

---

Dry Run

For:

s = "rabbbit"
t = "rabbit"

When characters match:

dp[i][j] = dp[i-1][j-1] + dp[i-1][j]

For example, when processing a matching "'b'", we can either:

- Take that "'b'"
- Ignore that "'b'"

This is what allows the DP to count all possible subsequences.

Final answer:

dp[7][6] = 3

---

Complexity

Let:

- "n = s.length()"
- "m = t.length()"

Time Complexity

O(n × m)

Space Complexity

O(n × m)

---

Key Idea

The most important observation is:

«When "s[i-1] == t[j-1]", either take the character or skip it.»

This gives the recurrence:

dp[i][j] = dp[i-1][j-1] + dp[i-1][j]

This is a classic 2D Dynamic Programming + Subsequence Counting problem.
