# 3876. Construct Uniform Parity Array II

## Problem Statement

You are given an array `nums1` of `n` distinct integers.

You need to construct another array `nums2` of the same length such that **all elements of `nums2` are either odd or all are even**.

For every index `i`, you can choose exactly one of:

* `nums2[i] = nums1[i]`
* `nums2[i] = nums1[i] - nums1[j]`, where `j != i` and the result is at least `1`

Return `true` if it is possible to construct such an array, otherwise return `false`.

---

## Approach

The important observation is:

### 1. If all numbers are even

We can simply keep every element unchanged.

So the answer is `true`.

### 2. If there are odd numbers

Let `minOdd` be the smallest odd number in the array.

For an even number `x`:

* If `x < minOdd`, we cannot make it odd using a valid subtraction.
* If `x > minOdd`, we can subtract `minOdd`:

```text
x - minOdd = even - odd = odd
```

Therefore, if **any even number is smaller than the smallest odd number**, the answer is `false`.

Otherwise, the answer is `true`.

### Why does this work?

For an odd number, we can simply keep it unchanged.

For every even number `x`:

```text
x > minOdd
```

Since `minOdd` is odd:

```text
even - odd = odd
```

Thus, every element can be made odd.

If there is an even number smaller than `minOdd`, there is no smaller odd number available to subtract from it, so it cannot be converted to odd.

---

## Algorithm

1. Find the smallest odd number `minOdd`.
2. If there is no odd number, return `true`.
3. Traverse the array again.
4. If an even number is smaller than `minOdd`, return `false`.
5. Otherwise, return `true`.

---

## C++ Solution

```cpp
class Solution {
public:
    bool uniformArray(vector<int>& nums1) {
        int minOdd = INT_MAX;

        // Find the smallest odd number
        for (int x : nums1) {
            if (x % 2 == 1) {
                minOdd = min(minOdd, x);
            }
        }

        // If there is no odd number,
        // all numbers are even
        if (minOdd == INT_MAX)
            return true;

        // Check if any even number is smaller
        // than the smallest odd number
        for (int x : nums1) {
            if (x % 2 == 0 && x < minOdd) {
                return false;
            }
        }

        return true;
    }
};
```

---

## Example 1

```text
Input:
nums1 = [1, 4, 7]

minOdd = 1
```

For `4`:

```text
4 - 1 = 3
```

So we can construct:

```text
nums2 = [1, 3, 7]
```

All elements are odd.

```text
Output: true
```

---

## Example 2

```text
Input:
nums1 = [2, 3]

minOdd = 3
```

Here:

```text
2 < 3
```

The even number `2` cannot subtract any smaller odd number.

Therefore:

```text
Output: false
```

---

## Example 3

```text
Input:
nums1 = [4, 6]
```

There are no odd numbers.

All elements are already even:

```text
nums2 = [4, 6]
```

Therefore:

```text
Output: true
```

---

## Complexity Analysis

Let `n` be the size of `nums1`.

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`

---

## Key Takeaway

The key is to find the **smallest odd number**.

* No odd numbers → `true`
* Every even number is greater than the smallest odd → `true`
* Any even number is smaller than the smallest odd → `false`

This gives an efficient `O(n)` solution.
