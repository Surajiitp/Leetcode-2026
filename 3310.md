# 3310. Remove Methods From Project

## Problem Statement

You are given:

- An integer `n` representing the number of methods in a project.
- An integer `k` representing the initially suspicious method.
- A list `invocations`, where `invocations[i] = [a, b]` means method `a` invokes method `b`.

A method becomes **suspicious** if it is reachable from method `k`.

You must remove all suspicious methods **only if** no non-suspicious method invokes any suspicious method.

Return the list of remaining methods after the removal.

---

## Approach

### Step 1: Build the Graph
- Represent method invocations using an adjacency list.

### Step 2: Find Suspicious Methods
- Perform a DFS starting from method `k`.
- Mark every reachable method as suspicious.

### Step 3: Validate Removal
- Traverse all invocation edges.
- If a non-suspicious method invokes a suspicious one, removal is impossible.
- In that case, return all methods.

### Step 4: Return Remaining Methods
- Otherwise, return every non-suspicious method.

---

## Algorithm

1. Create an adjacency list.
2. Run DFS from `k`.
3. Mark all reachable methods as suspicious.
4. Check every invocation:
   - If `!suspicious[u] && suspicious[v]`, return all methods.
5. Otherwise, return only non-suspicious methods.

---

## C++ Solution

```cpp
class Solution {
public:
    vector<int> remainingMethods(int n, int k, vector<vector<int>>& invocations) {
        vector<vector<int>> graph(n);

        for (auto &e : invocations)
            graph[e[0]].push_back(e[1]);

        vector<bool> suspicious(n, false);

        function<void(int)> dfs = [&](int u) {
            suspicious[u] = true;
            for (int v : graph[u]) {
                if (!suspicious[v])
                    dfs(v);
            }
        };

        dfs(k);

        for (auto &e : invocations) {
            int u = e[0], v = e[1];
            if (!suspicious[u] && suspicious[v]) {
                vector<int> ans;
                for (int i = 0; i < n; i++)
                    ans.push_back(i);
                return ans;
            }
        }

        vector<int> ans;
        for (int i = 0; i < n; i++) {
            if (!suspicious[i])
                ans.push_back(i);
        }

        return ans;
    }
};
```

---

## Complexity Analysis

- **Time Complexity:** `O(n + m)`
  - DFS visits each node and edge once.
  - One additional pass over all edges.

- **Space Complexity:** `O(n + m)`
  - Adjacency list.
  - Visited (suspicious) array.
  - DFS recursion stack.
