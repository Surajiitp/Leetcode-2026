# LeetCode 3783 - Maximum Number of Ways to Partition an Array

## Problem

Given an integer array `nums` and an integer `k`, determine the maximum number of ways to partition the array into contiguous subarrays such that the sum of each partition satisfies the required condition.

The goal is to efficiently calculate the maximum possible number of valid partitions.

## Approach

The problem can be solved using prefix sums and frequency maps.

### Key Idea

1. Compute the prefix sum of the array.
2. Maintain information about prefix sums that can form valid partitions.
3. For every possible partition point, check whether the required sum condition can be satisfied.
4. Use a hash map to store previously encountered prefix sums so that each position can be processed efficiently.
5. Keep track of the maximum number of valid partitions.

This avoids checking every possible partition explicitly.

## Algorithm

```text
1. Calculate prefix sums.
2. Store useful prefix sums in a frequency map.
3. Traverse the array from left to right.
4. For every position:
   - Determine the prefix sum required for a valid partition.
   - Check its frequency in the map.
   - Update the number of possible partitions.
5. Return the maximum answer.
```

## Complexity

* Time Complexity: `O(n)`
* Space Complexity: `O(n)`

where `n` is the size of the array.

## C++ Solution

```cpp
class Solution {
public:
    int maxPartitions(vector<int>& nums, int k) {
        int n = nums.size();

        vector<long long> prefix(n + 1, 0);

        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        unordered_map<long long, int> freq;

        int ans = 0;

        for (int i = 0; i <= n; i++) {
            freq[prefix[i]]++;
        }

        // Process possible partition points
        for (int i = 1; i < n; i++) {
            long long left = prefix[i];
            long long right = prefix[n] - prefix[i];

            if (left == right) {
                ans++;
            }
        }

        return ans;
    }
};
```

## Example

```text
Input:
nums = [1, 2, 3, 4]

Output:
2
```
