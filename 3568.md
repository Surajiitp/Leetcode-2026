# 3568. Minimum Moves to Clean the Classroom

## Problem

You are given an `m x n` grid representing a classroom.

Each cell can be:

* `S` → Starting position of the student
* `L` → Litter that must be collected
* `R` → Reset area that restores energy to maximum
* `X` → Obstacle that cannot be crossed
* `.` → Empty space

The student starts at `S` with `energy` units of energy.

Moving to an adjacent cell costs `1` unit of energy.

If the student enters an `R` cell, their energy is restored to the maximum value.

Return the **minimum number of moves required to collect all litter**.

If it is impossible, return `-1`.

---

## Example

### Example 1

```text
classroom = ["S.", "XL"]
energy = 2
```

Output:

```text
2
```

Path:

```text
S → .
    ↓
    L
```

The student reaches the litter in `2` moves.

---

## Example 2

```text
classroom = ["LS", "RL"]
energy = 4
```

Output:

```text
3
```

Path:

```text
S → L
↓
R → L
```

The reset cell restores the energy before moving to the second litter.

---

# Approach

The main difficulty is that the state is not determined only by the current position.

Two states at the same cell can be different if:

* They have different remaining energy.
* They have collected different litter.

Therefore, we represent every state using:

```text
(row, column, remainingEnergy, collectedMask)
```

Since there can be at most `10` litter cells, we can use a **bitmask** to represent which litter has been collected.

---

## Bitmask Representation

Suppose there are `3` litter cells.

We assign:

```text
L0 → bit 0
L1 → bit 1
L2 → bit 2
```

Initially:

```text
000
```

After collecting `L0`:

```text
001
```

After collecting `L0` and `L2`:

```text
101
```

When all litter is collected:

```text
111
```

In general:

```cpp
fullMask = (1 << litterCount) - 1;
```

---

# Why BFS?

Every movement costs exactly `1`.

Therefore, this is a shortest-path problem.

**BFS** explores all states in increasing order of number of moves.

So the first time we reach:

```cpp
mask == fullMask
```

we have found the minimum number of moves.

---

# Algorithm

### Step 1: Find the starting position

Scan the grid and store the position of `S`.

### Step 2: Assign an index to every litter

For every `L`, assign a unique bit index.

For example:

```text
L → 0
L → 1
L → 2
```

### Step 3: Create the full mask

If there are `L` litter cells:

```cpp
int fullMask = (1 << L) - 1;
```

### Step 4: Start BFS

Initial state:

```text
(startRow, startCol, energy, 0)
```

No litter has been collected initially.

### Step 5: Explore four directions

For every state, try:

```text
Up
Down
Left
Right
```

Skip:

```text
Outside grid
Obstacle 'X'
```

### Step 6: Consume energy

Every movement normally does:

```cpp
newEnergy = currentEnergy - 1;
```

### Step 7: Handle reset cell

If the destination is `R`:

```cpp
newEnergy = energy;
```

### Step 8: Collect litter

If the destination is `L`:

```cpp
newMask |= (1 << litterIndex);
```

### Step 9: Avoid duplicate states

We maintain:

```text
visited[row][col][energy][mask]
```

If the exact same state has already been visited, there is no reason to process it again.

### Step 10: Return answer

If:

```cpp
mask == fullMask
```

return the current BFS level.

If BFS finishes without collecting all litter:

```cpp
return -1;
```

# C++ Solution

```cpp
class Solution {
public:
    int minMoves(vector<string>& classroom, int energy) {
        int m = classroom.size();
        int n = classroom[0].size();

        int sr = 0, sc = 0;
        int litterCount = 0;

        vector<vector<int>> id(m, vector<int>(n, -1));

        // Find start and assign IDs to litter
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {

                if (classroom[i][j] == 'S') {
                    sr = i;
                    sc = j;
                }
                else if (classroom[i][j] == 'L') {
                    id[i][j] = litterCount++;
                }
            }
        }

        // No litter
        if (litterCount == 0)
            return 0;

        int totalMasks = 1 << litterCount;
        int fullMask = totalMasks - 1;

        // visited[row][col][energy][mask]
        vector<vector<vector<vector<bool>>>> visited(
            m,
            vector<vector<vector<bool>>>(
                n,
                vector<vector<bool>>(
                    energy + 1,
                    vector<bool>(totalMasks, false)
                )
            )
        );

        queue<tuple<int, int, int, int>> q;

        // row, col, remaining energy, collected mask
        q.push({sr, sc, energy, 0});
        visited[sr][sc][energy][0] = true;

        int dr[] = {-1, 1, 0, 0};
        int dc[] = {0, 0, -1, 1};

        int moves = 0;

        while (!q.empty()) {

            int sz = q.size();

            while (sz--) {

                auto [r, c, currEnergy, mask] = q.front();
                q.pop();

                // All litter collected
                if (mask == fullMask)
                    return moves;

                // No energy left
                if (currEnergy == 0)
                    continue;

                for (int k = 0; k < 4; k++) {

                    int nr = r + dr[k];
                    int nc = c + dc[k];

                    // Boundary
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n)
                        continue;

                    // Obstacle
                    if (classroom[nr][nc] == 'X')
                        continue;

                    int newEnergy = currEnergy - 1;
                    int newMask = mask;

                    // Reset energy
                    if (classroom[nr][nc] == 'R') {
                        newEnergy = energy;
                    }

                    // Collect litter
                    if (classroom[nr][nc] == 'L') {
                        newMask |= (1 << id[nr][nc]);
                    }

                    if (!visited[nr][nc][newEnergy][newMask]) {

                        visited[nr][nc][newEnergy][newMask] = true;

                        q.push({
                            nr,
                            nc,
                            newEnergy,
                            newMask
                        });
                    }
                }
            }

            moves++;
        }

        return -1;
    }
};
```

---

# Correctness

BFS guarantees the minimum number of moves because every transition represents exactly one move.

The state:

```text
(row, column, energy, mask)
```

contains all information necessary to determine future possibilities.

Therefore, if the same state is encountered again, processing it again cannot produce a better result.

When BFS first reaches a state where:

```cpp
mask == fullMask
```

all litter has been collected using the minimum possible number of moves.

Hence, the algorithm is correct.

---

# Complexity

Let:

```text
m = number of rows
n = number of columns
E = maximum energy
L = number of litter cells
```

There are at most:

```text
m × n × (E + 1) × 2^L
```

states.

Each state has at most `4` transitions.

Therefore:

```text
Time Complexity:
O(m × n × E × 2^L)

Space Complexity:
O(m × n × E × 2^L)
```

Since:

```text
L ≤ 10
```

we have:

```text
2^L ≤ 1024
```

which is manageable.

# Key Concepts

* Breadth-First Search
* State Space Search
* Bitmasking
* Grid Traversal
* Shortest Path
* Dynamic State Tracking
* Visited State Optimization

# Important Edge Cases

### 1. No litter

If there is no `L`:

```cpp
return 0;
```

### 2. Obstacle blocks the path

The BFS simply cannot enter `X`.

### 3. Energy becomes zero

No further movement is possible unless the student has already entered an `R` cell, because entering `R` immediately restores energy.

### 4. Reset cells

`R` can be used multiple times.

### 5. Same cell, different energy

These are different states:

```text
(row, col, 5, mask)
(row, col, 2, mask)
```

because their future movement possibilities are different.

### 6. Same cell and energy, different mask

These are also different states:

```text
(row, col, energy, 001)
(row, col, energy, 101)
```

because different litter has already been collected.

# Complexity Summary

| Metric       | Complexity                 |
| ------------ | -------------------------- |
| Time         | `O(m × n × E × 2^L)`       |
| Space        | `O(m × n × E × 2^L)`       |
| Search       | BFS                        |
| State        | `(row, col, energy, mask)` |
| Bitmask Size | At most `2^10 = 1024`      |

---

## Conclusion

The key idea is to combine **BFS + Bitmasking + Energy State**.

BFS gives the minimum number of moves, while the bitmask efficiently tracks which litter has been collected. Tracking remaining energy ensures that paths requiring different amounts of energy are handled correctly.

This gives an efficient solution within the given constraints.
