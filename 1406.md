## Problem Statement

Alice and Bob are playing a game with a row of stones represented by the array `stoneValue`.

- Alice always moves first.
- On each turn, a player can take the first **1, 2, or 3** stones.
- The value of the taken stones is added to the player's score.
- Both players play optimally.

Return:
- `"Alice"` if Alice wins.
- `"Bob"` if Bob wins.
- `"Tie"` if both have the same score.

stoneValue = [1,2,3,7]

## Approach (Dynamic Programming)

Instead of storing the total score, we store the **maximum score difference** the current player can achieve.

Let

```
dp[i]
```

represent the maximum score difference (Current Player − Opponent) starting from index `i`.

At every position, the player can pick:

- 1 stone
- 2 stones
- 3 stones

Transition:

```
dp[i] = max(
    sum(1 stone) - dp[i+1],
    sum(2 stones) - dp[i+2],
    sum(3 stones) - dp[i+3]
)
```

Finally,

- `dp[0] > 0` → Alice wins
- `dp[0] < 0` → Bob wins
- `dp[0] == 0` → Tie

---

## C++ Solution

```cpp
class Solution {
public:
    string stoneGameIII(vector<int>& stoneValue) {
        int n = stoneValue.size();
        vector<int> dp(n + 1, 0);

        for (int i = n - 1; i >= 0; i--) {
            dp[i] = INT_MIN;
            int sum = 0;

            for (int k = 0; k < 3 && i + k < n; k++) {
                sum += stoneValue[i + k];
                dp[i] = max(dp[i], sum - dp[i + k + 1]);
            }
        }

        if (dp[0] > 0) return "Alice";
        if (dp[0] < 0) return "Bob";
        return "Tie";
    }
};
```

## Key Takeaway

- DP stores **score difference**, not the actual score.
- Think from the **current player's perspective**.
- Compute answers from **right to left** because future states are required.
