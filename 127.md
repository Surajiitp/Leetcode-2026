# 🔤 LeetCode 127 — Word Ladder

## 📝 Problem

Given two words `beginWord` and `endWord`, and a dictionary `wordList`, find the **number of words in the shortest transformation sequence** from `beginWord` to `endWord`.

A valid transformation must satisfy:

* Each adjacent word differs by **exactly one character**.
* Every transformed word must exist in `wordList`.
* `beginWord` does not need to be present in `wordList`.
* The final word must be `endWord`.

If no valid transformation exists, return `0`.

---

## 💡 Example

### Input

```text
beginWord = "hit"
endWord = "cog"
wordList = ["hot","dot","dog","lot","log","cog"]
```

### Output

```text
5
```

### Explanation

The shortest transformation is:

```text
hit → hot → dot → dog → cog
```

There are **5 words** in the sequence.

---

## 🚀 Approach

We use **Breadth-First Search (BFS)** because we need to find the **shortest transformation sequence**.

### Step 1: Store the dictionary

Convert `wordList` into an `unordered_set`.

This allows us to check whether a generated word exists in the dictionary in approximately **O(1)** time.

```cpp
unordered_set<string> dict(wordList.begin(), wordList.end());
```

### Step 2: Check `endWord`

If `endWord` is not present in the dictionary, no valid transformation is possible.

```cpp
if (dict.find(endWord) == dict.end()) {
    return 0;
}
```

### Step 3: Start BFS

Push `beginWord` into a queue.

```cpp
queue<string> q;
q.push(beginWord);
```

We maintain `level` to represent the number of words in the current transformation sequence.

Initially:

```text
level = 1
```

because the sequence already contains `beginWord`.

### Step 4: Generate all possible transformations

For every character in the current word, replace it with every letter from `'a'` to `'z'`.

For example:

```text
hit
```

Changing the first character gives:

```text
ait
bit
cit
...
hot
...
zit
```

If the generated word exists in the dictionary, add it to the queue.

```cpp
if (dict.find(curr) != dict.end()) {
    q.push(curr);
    dict.erase(curr);
}
```

### Step 5: Avoid visiting words again

Once a word is added to the queue, remove it from the dictionary:

```cpp
dict.erase(curr);
```

This prevents revisiting the same word and keeps the BFS efficient.

---

## 🔍 Why BFS?

Imagine the transformation graph:

```text
        hot
       /   \
     dot    lot
      |      |
     dog    log
       \    /
        cog
```

Each word is a node, and an edge exists when two words differ by exactly one character.

BFS explores the graph level by level:

```text
Level 1: hit
Level 2: hot
Level 3: dot, lot
Level 4: dog, log
Level 5: cog
```

Therefore, the first time we reach `endWord`, we have found the **shortest transformation sequence**.

---

## 💻 C++ Solution

```cpp
#include <vector>
#include <string>
#include <unordered_set>
#include <queue>

using namespace std;

class Solution {
public:
    int ladderLength(string beginWord, string endWord,
                     vector<string>& wordList) {

        // Store all words in a set for O(1) average lookup
        unordered_set<string> dict(wordList.begin(), wordList.end());

        // If endWord is not present, transformation is impossible
        if (dict.find(endWord) == dict.end()) {
            return 0;
        }

        queue<string> q;
        q.push(beginWord);

        // beginWord itself counts as the first word
        int level = 1;

        while (!q.empty()) {

            int size = q.size();

            // Process all words at the current level
            for (int i = 0; i < size; ++i) {

                string curr = q.front();
                q.pop();

                // Destination reached
                if (curr == endWord) {
                    return level;
                }

                // Try changing every character
                for (int j = 0; j < curr.length(); ++j) {

                    char originalChar = curr[j];

                    // Replace current character with a-z
                    for (char c = 'a'; c <= 'z'; ++c) {

                        curr[j] = c;

                        // If generated word exists in dictionary
                        if (dict.find(curr) != dict.end()) {
                            q.push(curr);

                            // Mark as visited
                            dict.erase(curr);
                        }
                    }

                    // Restore original character
                    curr[j] = originalChar;
                }
            }

            // Move to the next BFS level
            level++;
        }

        return 0;
    }
};
```

---

## ⏱️ Complexity Analysis

Let:

* `N` = number of words in `wordList`
* `L` = length of each word

For every word, we try:

```text
L positions × 26 characters
```

So the time complexity is approximately:

```text
O(N × L × 26)
```

Since `26` is constant:

```text
O(N × L)
```

### Space Complexity

The dictionary and BFS queue can contain up to `N` words.

```text
O(N)
```

## 🔑 Important Interview Point

Whenever a problem asks for the **shortest number of steps** in an unweighted graph, **BFS** is usually the first approach to consider.

Here:

```text
Word = Node
One-letter transformation = Edge
Shortest transformation = Shortest path
```

Therefore:

```text
Word Ladder → BFS
```
