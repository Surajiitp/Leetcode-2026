LeetCode 122 — Best Time to Buy and Sell Stock II

🧩 Problem

You are given an integer array prices where prices[i] is the price of a stock on the i-th day.

You may complete as many transactions as you like:

Buy one stock and sell one stock.

You must sell the stock before buying again.

You can make multiple transactions.

Return the maximum profit you can achieve.

💡 Approach — Greedy

The key observation is:

Whenever today's price is greater than yesterday's price, take that profit.

For every pair of consecutive days:

if (prices[i] > prices[i - 1])
    profit += prices[i] - prices[i - 1];

This effectively captures every increasing part of the price graph.

Example

prices = [7, 1, 5, 3, 6, 4]

Profit:
(5 - 1) + (6 - 3)
= 4 + 3
= 7

So the maximum profit is:

7

🔑 Why This Works

Suppose prices continuously increase:

1 → 2 → 3 → 4

Instead of explicitly buying at 1 and selling at 4, we can calculate:

(2 - 1) + (3 - 2) + (4 - 3)
= 3

This gives exactly the same profit.

Therefore, every positive difference between consecutive prices should be added.

💻 C++ Solution

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0;

        for (int i = 1; i < prices.size(); i++) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }

        return profit;
    }
};

📊 Complexity Analysis

Time Complexity

O(n)

We traverse the array only once.

Space Complexity

O(1)

Only one variable is used to store the profit.

🧪 Example

Input

prices = [7, 1, 5, 3, 6, 4]

Output

7

Explanation

Buy at 1 and sell at 5 → profit 4

Buy at 3 and sell at 6 → profit 3

Total:

4 + 3 = 7

🧠 Key Takeaways

This problem can be solved using a Greedy approach.

Add every positive difference between consecutive prices.

No need for DP because unlimited transactions are allowed.

We only need O(1) extra space.

The solution scans the array once.
