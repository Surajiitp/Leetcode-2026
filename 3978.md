# 3978. Unique Middle Element

## Problem Statement

Given an integer array `nums` of odd length, determine whether the **middle element** appears **exactly once** in the array.

Return `true` if the middle element is unique; otherwise, return `false`.

---

## Approach

1. Find the middle element of the array using:
   ```cpp
   nums[nums.size() / 2]
   ```
2. Traverse the array and count the occurrences of the middle element.
3. If the count is exactly `1`, return `true`; otherwise, return `false`.

---

## C++ Solution

```cpp
class Solution {
public:
    bool isMiddleElementUnique(vector<int>& nums) {
        int mid = nums[nums.size() / 2];
        int cnt = 0;

        for (int x : nums) {
            if (x == mid)
                cnt++;
        }

        return cnt == 1;
    }
};
```

---

## Example

### Input

```text
nums = [1, 2, 3]
```

### Output

```text
true
```

### Explanation

- Middle element = `2`
- It appears exactly once in the array.
- Hence, the answer is `true`.
